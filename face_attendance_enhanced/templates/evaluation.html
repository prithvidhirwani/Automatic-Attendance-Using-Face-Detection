How to read these numbers

  • Detection = finding a face box. Recognition = naming it. Unknown rejection = refusing to name someone who is not registered. They are reported separately.
  • Identity accuracy = correctly identified registered faces ÷ registered faces actually in the image(s). Example: 4 of 6 gives 66.67%. Faces the detector missed count as not identified.
  • Detection precision/recall need face-box annotations: a detection is correct when it overlaps an annotated box with IoU ≥ {{ cfg.IOU_THRESHOLD }}. Without boxes they show n/a; the per-image “missed / false det.” are then only count differences.
  • Modes: box judges each face by position. single uses the largest detected face. set (group, no boxes) can only check whether the right names appear, not where — treat it as an approximation.
  • Precision / recall / F1 are computed per identity from (actual, predicted) pairs, then macro-averaged (each identity counts equally) and weighted-averaged (by number of faces). A missed face lowers recall for that identity.
  • LBPH distance is not a probability. Results apply to your data, lighting and threshold only.
